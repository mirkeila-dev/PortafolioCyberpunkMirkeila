
# Portafolio Web Profesional - Mirkeila Gomez

## Descripción
Portafolio web profesional con estética cyberpunk, fondo animado inspirado en Matrix y modos oscuro y claro. Desarrollado como proyecto académico de Inteligencia Artificial.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome
- Google Fonts

## Funcionalidades
- Diseño adaptable a dispositivos móviles.
- Cambio entre modo oscuro y claro.
- Animación de fondo Matrix.
- Galería de proyectos con filtros.
- Sección de experiencia profesional.
- Videos integrados de YouTube.
- Formulario de contacto.

## Publicación
Sitio web publicado mediante GitHub Pages.
